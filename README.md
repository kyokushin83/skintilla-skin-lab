# SKINTILLA Skin Lab

부산 기장 해양자원과 스킨케어 루틴을 연결하는 한국어 정적 웹사이트입니다. 빌드나 API 키 없이 실행할 수 있습니다. 이 폴더의 파일을 함께 유지하고 `index.html`을 열면 됩니다.

## 피부 테스트

- 얼굴 사진은 선택 사항입니다. 브라우저에서 사진 중앙 타원의 밝기 분포와 색조를 샘플링합니다. 얼굴 위치는 사용자가 점선으로 확인합니다. 사진 파일과 설문 답변은 서버로 전송하거나 저장하지 않습니다.
- 추천은 여섯 가지 설문 응답으로 생성합니다. 우선 관리 고민과 응답에서 가장 강하게 나타난 추가 고민을 고려해 성분, 제형, AM·PM 사용 순서와 횟수를 제안합니다.
- 미역과 다시마는 기장 해양원료 연구 후보로 안내합니다. 완제품 효능을 뜻하지 않습니다.
- 일반적인 보습제 가이드는 [미국피부과학회 보습제 안내](https://www.aad.org/public/everyday-care/skin-care-basics/dry/pick-moisturizer)를 참고했습니다.

## 제품 등록

1. `admin.html`을 열어 제품명, 제형, HTTPS 제품 링크, 추천 고민 태그를 입력합니다.
2. 출시 제품으로 표시한 후 목록에 저장하고 `products.js`를 내려받습니다. 내려받는 파일에는 출시 상태 제품만 포함됩니다. 편집 중 목록은 현재 탭에만 있습니다.
3. GitHub 저장소의 `products.js`를 내려받은 파일로 교체해 커밋합니다. 배포 후 제품의 태그와 제형이 모두 해당하는 결과 화면에 제품이 표시됩니다.

웹 편집 화면은 파일을 준비하는 도구입니다. 공개 카탈로그 변경 권한은 GitHub 저장소 쓰기 권한으로 관리합니다. 향후 권한이 있는 관리자용 서비스로 전환할 경우 `id`, `name`, `type`, `url`, `goals`, `published` 레코드를 같은 형식으로 제공하면 추천 로직을 재사용할 수 있습니다.
